# Project Diagrams

## Producer strategic BPMN

The producer-side model for [issue #15](https://github.com/sungurz/bristol-food-marketplace/issues/15) covers product and stock management, order fulfilment, settlement reconciliation, food safety and community activity.

- [Editable Camunda BPMN model](strategic-producer.bpmn)
- [Exported overview](strategic-producer.png)
- [Reading guide, assumptions and modelling scope](../docs/strategic-producer-guide.md)

The five grouped process views represent one producer. Shared product, order and accounting records show how the processes relate. The model is descriptive and intentionally non-executable; the guide explains the Camunda deployment notices and the work needed for later process automation.
